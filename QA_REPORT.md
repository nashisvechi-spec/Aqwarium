# Проверка исправлений аквариума — 8 октября 2026 года

Исходная точка: `9faef7161e8940b67c79aeacbaffba62b30792fd`. Файл `preview/Aquarium_Test_v2.html` в этой ревизии полностью совпал с актуальной тестовой версией. Дополнительные проверки нашли ошибки, которые прежние 79 + 7 сценариев не выявляли.

## Воспроизведённые ошибки

1. При временном размере canvas 0 × 0 движение использовало деление на ноль. После возвращения нормального экрана координаты всех семи стартовых рыб становились нечисловыми, а Canvas выбрасывал ошибку `createLinearGradient`. Отрисовка останавливалась.
2. После `AquariumLifecycle.suspend()` загрузка сохранения снова запускала таймеры, хотя приложение оставалось свёрнутым. За 0,6 секунды теста время аквариума продвинулось на 0,589 секунды.
3. При `QuotaExceededError` запись в localStorage прерывала `persist()` до Android-моста. Число попыток записи нативного checkpoint было нулевым.

## Исправления

- Последние положительные размеры экрана сохраняются, пока WebView сообщает нулевую ширину или высоту.
- Анимация, отрисовка, видимый пересчёт времени и периодическое сохранение учитывают нативное сворачивание. Android синхронизирует состояние также при завершении загрузки страницы.
- Запись Android-checkpoint не зависит от доступности localStorage. При старте проверяются обе копии; некорректная новая композиция не блокирует восстановление корректной старой.
- Локальные checkpoint со значениями `null`, возникшими из повреждённых координат, восстанавливают положение рыб. ID, окрасы и корректные показатели сохраняются. Проверка импортируемых файлов остаётся строгой.
- Manifest задаёт `sensorLandscape`. Вертикальный браузерный экран показывает просьбу повернуть устройство.
- Workflow APK запускается только через `workflow_dispatch`, поэтому push исправлений не создаёт APK.
