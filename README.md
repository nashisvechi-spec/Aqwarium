# Тихая вода — аквариум для Android

Исходники тестовой версии 1.0.0-preview. Аквариум занимает весь экран; меню открываются отдельно, а состояние рыбки показывается по нажатию на неё. Android-приложение работает только горизонтально, включая поворот на 180°. В браузере при вертикальном экране появляется просьба повернуть устройство.

8 октября 2026 года исправлены остановка рыб после временного нулевого размера экрана, запуск симуляции во время сворачивания и ошибки сохранения при переполнении браузерного хранилища. Старые локальные сохранения с повреждёнными координатами восстанавливаются с сохранением рыб, окраса и остальных корректных показателей. Изображения не заменялись; APK для этих исправлений не создавался.

## Что входит

| Состав | Количество |
|---|---:|
| Виды обитателей: неон, гуппи, скалярия, золотая рыбка, цихлида, форель, щука, креветка, петушок | 9 |
| Изображения обитателей с вариантами окраса | 14 |
| Украшения и растения | 10 |
| Фоны | 4 |
| Новые изображения всего | 28 |

У гуппи четыре окраса, у петушка три. Окрас сохраняется у каждой особи. Все новые изображения уже подключены к приложению. PNG в `art-source/` содержат оригиналы в нативном разрешении генерации; WebP в `web/assets/` подготовлены для телефона. Фоны имеют размер 1672 × 941, размеры остальных оригиналов перечислены в `art-source/manifest.json`. Изображения рыб и декора имеют прозрачный фон.

Сохранены три плана глубины, расстановка и поворот предметов, история отмены, лампы, цветовые фильтры, тени, территории рыб, кормление, показатели состояния и импорт новых обитателей через JSON / ZIP.

При ×1 время календарное: сутки равны 24 часам. Рост ускорен в 8 раз. Голод от 0 до 100 развивается за 36 часов. По умолчанию хищники могут есть рыб только при голоде 90; явные правила импортированного вида имеют приоритет. Щука появляется длиной 20–26 см, растёт до 45 см, охотится внутри территории с голода 80 и выходит за её пределы с голода 90. В спокойном режиме рыбки не поедают соседей.

При закрытии приложение сохраняет состояние. При следующем открытии движок пересчитывает прошедшее время, рост, голод и состояние рыб. Фонового Android-сервиса нет. Пауза останавливает и этот пересчёт. Экономный режим по умолчанию ограничивает отрисовку до 20 кадров/с.

## Установить APK

Скачайте `Aquarium-1.0.0-preview.apk` и откройте его на Android 8.0 или новее. При запросе системы разрешите установку приложений для того приложения, из которого открыли APK. У приложения отдельный идентификатор `ru.quietwater.aquarium`.

Сборка работает без доступа к интернету. Импорт и экспорт выполняются через системный выбор файла; отдельное разрешение на весь накопитель не требуется. Автосохранение хранится внутри приложения. Перед удалением приложения сохраните аквариум в JSON через раздел «Наборы и сохранения».

APK подписан ключом **preview** из `keystores/aquarium-preview.jks`. Он намеренно находится в проекте: пароль `android`, alias `aquarium-preview`. Это позволяет повторным сборкам из этого проекта обновлять установленную тестовую версию. Для публикации в Google Play создайте отдельный закрытый ключ, настройте подпись и проверьте актуальные требования Google Play. Не используйте публичный preview-ключ для производственной публикации.

## Собрать через GitHub

1. Распакуйте архив и поместите **его содержимое в корень репозитория**, включая скрытую папку `.github/`. Не загружайте архив ZIP как единственный файл.
2. Отправьте проект в ветку `main` или `master`. Если GitHub запрашивает включение Actions, включите их. Отправка кода запускает только проверки.
3. Когда понадобится APK, откройте **Actions → Build Android APK** и нажмите **Run workflow**. Сборка запускается только вручную.
4. После успешного выполнения скачайте артефакт **Aquarium-Android-APK**. Внутри находятся APK и его SHA-256.

Второй workflow **Test aquarium** запускает проверку симуляции, импорта, сохранений, изображений и мобильного интерфейса. В артефакте **Aquarium-test-results** будут отчёт и снимки экрана.

## Собрать на компьютере

Нужны JDK 17, Android SDK 35 и Build Tools 35.0.0. В Android Studio откройте корневую папку проекта и дождитесь синхронизации. SDK можно указать через `ANDROID_HOME` либо строкой `sdk.dir=...` в локальном файле `local.properties`.

Linux / macOS:

```bash
chmod +x gradlew
./gradlew --no-daemon assembleRelease lintRelease
```

Windows:

```bat
gradlew.bat --no-daemon assembleRelease lintRelease
```

Результат: `app/build/outputs/apk/release/app-release.apk`. В проекте зафиксированы Gradle 8.11.1 и Android Gradle Plugin 8.9.2. При создании обновления увеличьте `versionCode` в `app/build.gradle`.

## Проверить в браузере

Переносимая версия находится в `preview/Aquarium_Test_v2.html`: её можно открыть без сервера. Чтобы пересобрать её из текущего кода, выполните:

```bash
python3 tools/export_html.py
```

Для работы с исходниками удобно запускать локальный сервер:

```bash
python3 -m http.server 8080 --directory web
```

Откройте `http://localhost:8080`. Автоматические проверки запускаются отдельно:

```bash
npm ci --ignore-scripts
npx playwright install chromium
npm test
```

## Новые наборы

В разделе «Наборы и сохранения» нажмите «Загрузить JSON / ZIP». JSON может содержать рыб и декор; изображения задаются как `data:image/png;base64,...`, `data:image/jpeg;base64,...` либо `data:image/webp;base64,...`. Пример JSON можно сохранить прямо из меню приложения.

ZIP содержит `manifest.json` с тем же JSON-форматом и отдельные изображения. Значение `image` в манифесте — относительный путь к картинке внутри ZIP. Лимит входного файла — 8 МБ, набора после встраивания картинок — 2 МБ, одной картинки в поле `image` — 900 000 символов. В ZIP допускается до 70 файлов; размер одного распакованного файла — до 2 МБ, сумма — до 8 МБ.

## Структура проекта

- `app/` — Android-оболочка, автосохранение и системный импорт / экспорт.
- `web/` — интерфейс, симуляция и оптимизированные изображения.
- `art-source/` — 28 оригиналов PNG и манифест размеров / контрольных сумм.
- `ART_PROMPTS.json` — запросы для создания всех 28 изображений.
- `preview/` — автономный HTML для браузера.
- `tests/` — проверки, `screenshots/` — снимки проверенного интерфейса.
- `.github/workflows/` — сборка Android и проверка приложения.
- `QA_REPORT.md` и `qa/` — результаты проверки этой сборки.

Текущий код прошёл 79 сценариев основной версии, 7 сценариев автономного HTML и 17 проверок жизненного цикла и сохранений в Chromium. Manifest проверен на горизонтальную ориентацию, а workflow APK — на ручной запуск. Проверка сборки, подписи APK и Android Lint относится к предыдущей версии от 7 октября. Для исправлений от 8 октября APK не создавался. На физическом телефоне эти изменения ещё не проверялись.
